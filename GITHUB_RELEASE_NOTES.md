# GITHUB_RELEASE_NOTES — v1.0-hackathon-submission

## What this project is

PYRIN-PLAQUE Digital Twin is an auditable Claude Science workflow that separates
MEFV/pyrin inflammasome biology from the saturated NLRP3-in-atherosclerosis
literature, and maps a caveated myeloid pyrin-permissiveness hypothesis in
public human carotid plaque data. It is public-data-only, reproducible (pinned
environment, named scripts, checksums), and auditable (six reviewer-agent
gates with full provenance).

**It is an auditable hypothesis engine, not a validated target claim.**

## What was found

- **Single-cell (GSE159677, 49,380 cells post-QC):** MEFV is sparse overall
  (~0.97%) but myeloid-enriched (Macrophage/Myeloid 4.3%). PYRIN_BACKBONE is
  highest in Macrophage/Myeloid (specificity delta +0.74) and survives
  shared-downstream exclusion (PYCARD/CASP1/GSDMD/IL1B/IL18 excluded from
  discriminative scoring). Random matched gene-set control is modest
  (~82nd percentile) — suggestive, not definitive.
- **AC-vs-PA bridge:** MEFV detection rises in plaque core in 3/3 patients,
  but the composite PYRIN_BACKBONE does not consistently rise — a mixed
  result, reported honestly rather than hidden.
- **Bulk (GSE120521, n=4 paired):** PYRIN_BACKBONE is higher in unstable
  plaque in 4/4 patients (d=1.44), but the effect collapses under myeloid
  residualization (+0.72 → +0.14, p≈0.69) — directionally supportive but
  myeloid-abundance-confounded.
- **ODE digital twin:** dimensionless, uncalibrated pyroptosis model; global
  sensitivity analysis shows generic inflammatory priming dominates over the
  pyrin-specific activation threshold — hypothesis-generating only.
- **Priority ranking:** the MEFV/pyrin threshold axis ranks top (37.9,
  moderate confidence); no candidate reaches high confidence; myeloid-
  confounded and mixed signals are penalty-suppressed rather than dropped.

## How to reproduce

```bash
conda env create -f environment.yml      # or: pip install -r requirements-freeze.txt
make smoke    # fast integrity check — no raw data needed
make test     # unit tests
make all      # full path — requires public GEO downloads, see DATA_LICENSE.md
```

Checksum verification of the archived submission package:
```bash
shasum -a 256 -c PACKAGE_CHECKSUM.txt
```

At packaging time, `make smoke` returned **PASS** and `make test` returned
**13/13 passed**. These checks were re-run during GitHub repo preparation on
this machine (system Python 3.14 + a throwaway virtualenv with the pinned
dependencies) and reproduced the same result: smoke PASS, 13/13 tests passed.

## Known limitations

- Sparse MEFV expression (~0.97% of cells)
- Provisional marker-based cell-state labels (no published per-cell labels)
- n=3 single-cell patients, n=4 bulk patients (FPKM only, no raw counts)
- Bulk pyrin signal is myeloid-abundance-confounded
- AC/PA compartment signal is mixed
- No MEFV genotype / FMF stratification
- ODE is dimensionless and uncalibrated — not a clinical prediction model
- The integrated atlas (PMID 40931012) was not used as a data source, only
  as literature precedent
- Public data only; no private data, no PHI

## Final safe claim

PYRIN-PLAQUE identifies a suggestive myeloid pyrin-permissiveness pattern and
prioritizes the MEFV/pyrin threshold axis for future validation, while
showing that much of the bulk signal is myeloid-abundance-confounded and that
generic inflammatory priming may dominate over pyrin-specific threshold
effects. It is an auditable hypothesis engine — not a validated target, and
not a clinical or causal claim.
