# Claude Science Usage Statement — PYRIN-PLAQUE Digital Twin

How Claude Science was used **beyond chat** to build an auditable, public-data-only workbench.

## 1. MCP connectors used
- **omics-archives (GEO)** — dataset discovery + metadata verification (GSE159677, GSE120521, GSE253902, GSE159677 sample structure).
- **pubmed** — literature search and metadata across 5 evidence axes; anchor-paper resolution.
- **genes-ontologies (MyGene)** — validation of all 22 module gene symbols → Ensembl/Entrez/UniProt (taxid 9606).
- **chembl + clinical-genomics (Open Targets)** — target existence, tractability buckets, mechanisms.
- **clinical-trials** — verification of CANTOS (NCT01327846), COLCOT (NCT02551094), LoDoCo2 (NCT03048825).
- **protein-annotation (InterPro)** — MEFV domain architecture (PYD/B-box/B30.2).

## 2. Literature evidence extraction
57 reviewer-gated claims across 5 axes assembled into an evidence graph (evidence/evidence_graph.jsonl, claim_cards.md), with a method-precedent matrix establishing conservative novelty framing.

## 3. Dataset verification
Each candidate dataset verified through live connector calls; the integrated atlas (PMID 40931012) was **excluded as a data source** (NEEDS_REVIEW) and used only as literature precedent. Gene modules frozen v0.

## 4. Public omics analysis
Single-cell scoring (GSE159677: 49,380 cells, PYRIN/NLRP3 backbone scores, specificity delta, random + donor controls) and bulk triangulation (GSE120521: paired stable/unstable, myeloid-confounding residualization), plus a dimensionless pyroptosis ODE with 4 scenarios and global sensitivity.

## 5. Figure generation
Five main figures, each generated by a named script in a pinned conda environment, with a figure card and checksum (audit/day6_final_figure_inventory.csv).

## 6. Provenance capture
Package versions, script/figure/table checksums, environment lock, and input checksums recorded (audit/day3_provenance.json, requirements-freeze.txt). Numba cache fix documented for reproducibility.

## 7. Reviewer-agent gates
- **Day 1 — data gate:** PROCEED_WITH_CAVEATS (flagged shared-downstream circularity + atlas).
- **Day 2 — claim gate:** 56 PASS / 1 FLAG of 57 claims.
- **Day 3 — single-cell figure/data gate:** 9 PASS / 1 FLAG.
- **Day 4 — bulk/ODE gate:** 11 PASS / 2 FLAG (myeloid confounding; AC/PA mixed).
- **Day 5 — priority/ODE/target-card gate:** 13 PASS / 0 FLAG.
- **Day 6 — final cross-artifact audit.**

## 8. Corrections made because of reviewer agents
- **Shared downstream exclusion** — PYCARD/CASP1/GSDMD/IL1B/IL18 removed from discriminative pyrin-vs-NLRP3 scoring.
- **Integrated atlas excluded** as a data source (kept as literature precedent only).
- **Provisional labels** — single-cell annotations explicitly labeled provisional marker-based.
- **Myeloid confounding carried forward** — bulk pyrin signal shown to collapse under myeloid residualization.
- **AC/PA mixed signal carried forward** — core MEFV rise vs non-rising composite pyrin program reported honestly.
- **Generic priming > pyrin threshold verdict** — stated from ODE sensitivity.
- **No high-confidence target** — priority score caps at moderate; nothing graded high.
- **External auditor fixes** — GSDME reassigned to GENERIC_PYROPTOSIS; GSE120521 pairing reworded as assumption.
